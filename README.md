# structured-programming-labs

Учебный репозиторий: 24 небольших консольных проекта на трёх языках — **8 на PHP, 8 на C#, 8 на C++**.

Все проекты написаны по правилам **структурного программирования** и решают задачи одного класса — обработка и контроль данных (профилирование CSV, проверки Data Quality, разбор логов выполнения, отчётные периоды, метрики временных рядов). Такой набор даёт возможность сравнить, как одна и та же декомпозиция выглядит в трёх разных языках.

## Правила, которым подчинён код

1. **Один вход и один выход** у каждой функции: ровно один `return` в конце (допускаются ранние выходы только в `main` и в валидаторах, где это защитная проверка аргументов).
2. **Никакого `goto`, `break` с метками, исключений как потока управления** — только последовательность, ветвление и цикл с одним условием выхода.
3. **Декомпозиция сверху вниз**: каждая задача разбита на функции длиной 10–25 строк, каждая функция делает одно дело.
4. **Данные передаются явно** через аргументы, глобального изменяемого состояния нет.
5. **Ввод-вывод отделён от вычислений**: функции расчёта чистые, печать отчёта — отдельная функция.
6. **Ошибки обрабатываются возвратом кода состояния** (`int` из `main`) и сообщением в stderr, а не падением с трейсом.
7. **Никакого ООП ради ООП**: в PHP и C++ используются функции и структуры, в C# — статические методы; класс применяется только как контейнер там, где его требует рантайм.

## Структура

```
structured-programming-labs/
├── data/                  общие входные данные для всех языков
│   ├── sample.txt         текст для частотного анализа
│   ├── clients.csv        выгрузка по клиентам банка (с дефектами качества)
│   ├── queries.log        лог выполнения задач загрузки
│   └── balance.csv        временной ряд остатков по месяцам
├── php/     8 проектов, каждый — папка с index.php
├── csharp/  8 проектов, каждый — папка с Program.cs и .csproj
└── cpp/     8 проектов, CMakeLists.txt на все цели
```

## Запуск

**PHP 8.1+**

```bash
php php/01-text-stats/index.php data/sample.txt
```

**C# (.NET 8 SDK)**

```bash
dotnet run --project csharp/TextStats -- data/sample.txt
```

**C++ (CMake 3.16+, компилятор с C++17)**

```bash
cmake -S cpp -B cpp/build
cmake --build cpp/build
./cpp/build/01_text_stats data/sample.txt
```

Пути к данным по умолчанию заданы относительно папки проекта, поэтому каждый пример можно запускать и без аргументов — программа возьмёт файл из `data/`.

## Что показывают проекты

- уверенное владение базовым синтаксисом и стандартной библиотекой трёх языков;
- умение разбить задачу на функции так, чтобы её можно было прочитать без отладчика;
- понимание, что такое «грязные» данные: пустые значения, дубли, нарушенные диапазоны, часовые пояса и форматы дат;
- аккуратную работу с числами с плавающей точкой и агрегатами (перцентили, скользящее среднее).
